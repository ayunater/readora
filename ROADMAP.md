# Roadmap

Ideas for version 2. Nothing here is a promise; it is a list of what v1 deliberately does not do yet.

## Reading
- **Find bar** inside the viewer (Ctrl+F, next/previous hit, hit count). Today search lives in *Tools*.
- **Select and copy text** from the page.
- **Outline / bookmarks panel** next to the thumbnails.
- **Resume where you left off**: remember page and zoom per file.
- Keyboard shortcut cheat sheet (Ctrl+O open, Ctrl+P print, Ctrl+G go to page).
- Remember window size and position; follow the system dark/light setting.
- Single-instance mode: opening a PDF from the file manager while Readora is running reuses the window
  (today each launch opens its own window).

## Editing
- **Edit existing text** in place (v1 adds new content on top of the page).
- **Sticky notes, comments and real highlight/underline/strike-through annotations** that other readers show
  in their annotation panels.
- **Fill in forms** (AcroForm fields) and **sign** with a drawn or typed signature.
- Edit text with arbitrary system fonts; alignment buttons; rotate and flip placed items; snap and align guides.
- Copy and paste items between pages and between documents.
- Insert pages from another PDF; delete the current page from the viewer.

## Tools
- Redact by searching for text (v1 redacts the areas you draw).
- Compress / optimise a PDF; flatten annotations.
- OCR for scanned documents.
- Compare two PDFs.
- Batch operations (merge folders, watermark many files).
- Bookmarks and page labels editor.

## Project
- Code-signed Windows installers; macOS and Linux (`.rpm`) installers.
- UI-level automated tests (the current suite covers document, storage, editor, SVG and association logic).
